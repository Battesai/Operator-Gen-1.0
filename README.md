# Operator-Gen-1.0

iPhone-optimized PWA for **Project Operator 2.0**.

## Publish with GitHub Pages
1. Upload all files in this repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save.
6. Open the Pages URL in Safari on iPhone.
7. Share → **Add to Home Screen**.

The app works offline after the first successful load.
